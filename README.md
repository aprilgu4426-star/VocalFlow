# VocalFlow

面向香港职场人士的英语口语练习单页原型，品牌为 VocalFlow。页面包括跟读练习、商务场景语料库、节奏训练和发音知识库。

## 运行

在项目目录启动本地静态服务器：

```sh
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。麦克风录音需要安全上下文；localhost 或 HTTPS 均可。

## 当前功能

- 练习、场景语料、节奏训练和发音知识四个板块；语料覆盖会议、客户电话、演示、社交和协商。
- 场景语料提供影子跟读短句、节奏/弱读/连读/语调提示及部分易读错单词 IPA 参考。
- 使用浏览器语音引擎播放英式英语示范音频。
- 使用麦克风录音并回放本次录音。
- 录音时实时绘制本地声音振幅，并保留整段录音的波形供练习者参考。
- 使用节拍器和渐进式扩句练习英语节奏，并通过三题闯关巩固发音规则。
- 在浏览器支持 Web Speech API 时，将识别文本与原句做文字匹配度估算。
- 浏览器不支持语音识别时，录音和回放仍可使用。

文字匹配度不比较音频波形、音素、口音或语调，不应作为发音准确度评分。波形仅显示麦克风输入的声音振幅，不自动诊断发音。语料提示和 IPA 是学习参考，并非针对每位学习者的自动反馈。示范音频是浏览器合成语音，不是真人录音。浏览器语音识别服务可能会将音频发送给浏览器提供方；页面本身不会上传或保存录音。

若要达到真实口音训练的目标，下一步需要接入真人录制的标准音频，以及能在音素或声学层面评估发音的语音服务，并明确其音频保留与隐私政策。
