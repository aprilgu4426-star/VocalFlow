# VocalFlow

面向香港职场人士的英语口语练习单页原型，品牌为 VocalFlow。页面包括跟读练习、商务场景语料库、节奏训练和发音知识库。

## 运行

在项目目录启动本地静态服务器：

```sh
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。麦克风录音需要安全上下文；localhost 或 HTTPS 均可。

## 当前功能

- 练习、场景语料、节奏训练和发音知识四个板块；语料覆盖会议、客户电话、演示、社交和协商。
- 场景语料覆盖会议、客户电话、演示、社交、协商、面试和团队协作，提供短句与完整长段落。
- 所有短句也在原文中直接标注重音、弱读、连读、语调升降和易错词 IPA，并提供统一的颜色/线型图例。
- 长段落在完整职场语境中直接标注主重音、连读、弱读、语调升降和易错词 IPA；可直接选中整段进行跟读、录音和回放。
- 使用浏览器语音引擎播放英式英语示范音频。
- Practice 播放 model voice 时同步显示随播放进度移动的语调曲线；浏览器不提供合成语音的实际波形，此曲线是视觉参考而非测得的声学数据。
- 使用独立回放按钮试听本次录音；无需依赖语音识别是否成功。
- 录音时显示本地麦克风振幅；录音完成后尝试提取基频曲线，并与按语句标点生成的建议语调曲线叠加显示。
- 节奏训练包含 6 类场景、24 条逐句练习语料；可选择语速并播放浏览器合成领读，节拍器随领读起声同步启动。
- 使用节拍器和渐进式商务短句练习英语节奏，并通过三题闯关巩固发音规则。
- 在浏览器支持 Web Speech API 时，将识别文本与原句做文字匹配度估算。
- 浏览器不支持语音识别时，录音和回放仍可使用。

文字匹配度不比较音素、口音或语调，不应作为发音准确度评分。Practice 中随 model voice 显示的曲线是根据文本生成并随播放进度移动的语调参考，浏览器不提供合成语音的实际音频波形或实测音高。节奏训练的浏览器合成语音按所选 BPM 调整播放速率，并与节拍器在语音开始时同步启动；具体词语的落拍会因浏览器和语音而异，不能保证完全精准。用户录音曲线是浏览器对录音的基频估算；对比图中的建议曲线只是按文本标点生成的示意，并非标准范读录音或逐词对齐的正确答案。短录音或清晰浊音不足时，浏览器可能无法提取稳定基频。语料提示和 IPA 是学习参考，并非针对每位学习者的自动反馈。示范音频是浏览器合成语音，不是真人录音。浏览器语音识别服务可能会将音频发送给浏览器提供方；页面本身不会上传或保存录音。

若要达到真实口音训练的目标，下一步需要接入真人录制的标准音频，以及能在音素或声学层面评估发音的语音服务，并明确其音频保留与隐私政策。
